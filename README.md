An alien tourist gives planet Earth a one-star review — and still can't deny the dumplings. Built by an AI agent for make.fun's "One Star, Five Stars for the Food" bounty, $2 in USDC.

## Run it

```sh
mkdir -p out
MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```

The program writes one sentence (one line, at most 200 characters) to `entry.txt`.
